# ResetSelf P0 任务拆解清单

## 1. 目标

P0 的唯一目标是：先把“可用闭环”做出来。

闭环定义：

`引导 -> 首次重构 -> 首页身份卡 -> 每日校验 -> 惯性样本沉淀`

## 2. 任务分组

### A. 数据层

#### A1. 数据库初始化

- 建立数据库入口与版本号
- 初始化 6 张核心表
- 初始化基础索引
- 启用外键约束

完成标准：

- 首次启动可自动建表
- 再次启动不重复报错

#### A2. 用户主档

- 建立 `user_profile` 读写
- 保证全局唯一主记录
- 读取当前身份与最小行动

完成标准：

- 首页可直接读取主档

#### A3. 首次重构记录

- 建立 `restructure_record` 写入能力
- 支持 `is_latest` 版本切换
- 写入年份字段

完成标准：

- 完成首次重构后存在一条最新记录

#### A4. 信念与样本

- 建立 `limiting_belief` 写入
- 建立 `inertia_sample` 写入与查询
- 建立 `daily_checkin` 写入与去重

完成标准：

- 每日校验与 SOS 后均可生成样本数据

### B. 状态与路由

#### B1. 应用状态中心

- 管理初始化状态
- 管理当前用户主档
- 管理首次重构是否完成
- 管理加载与错误态

完成标准：

- 页面不直接散落写状态

#### B2. 路由守卫

- `bootstrap`
- `onboarding`
- `restructure`
- `home`
- `checkin`
- `insights`
- `sos`

规则：

- 未完成首次重构：只能访问引导与重构向导
- 已完成首次重构：默认进入首页

完成标准：

- 不能跳过首次重构直接进入核心页

### C. 页面实现

#### C1. Onboarding

- 真空模式欢迎页
- 说明“无打卡、无评判、低阻力”
- 提供进入首次重构向导入口

完成标准：

- 页面风格与原型一致

#### C2. 首次重构向导

- 反愿景
- 底层恐惧
- 限制性信念
- 新身份叙事
- 极简行动

完成标准：

- 每页只有一个问题
- 可前进、后退
- 输入支持软提示

#### C3. 首页

- 展示身份宣言
- 展示明日最小行动
- 展示今日校验按钮
- 展示 SOS 悬浮按钮

完成标准：

- 数据来自 SQLite，而非写死文案

#### C4. 每日校验

- 三态选择页
- 完成反馈页
- 自动回首页

完成标准：

- 每次校验都写入数据库

#### C5. SOS

- 深色急救页
- 两到三个快速标签
- 返回首页与重新进入重构入口

完成标准：

- 选择标签后产生样本记录

#### C6. 洞察页

- 展示最近样本列表
- 展示状态标签与时间

完成标准：

- 列表来自真实数据库

### D. 业务逻辑

#### D1. 首次重构提交

- 提交后更新 `user_profile`
- 写入 `restructure_record`
- 写入 `limiting_belief`
- 写入初始化样本

完成标准：

- 首页实时显示新的身份与最小行动

#### D2. 每日校验逻辑

- 写入 `daily_checkin`
- 根据状态写入 `inertia_sample`
- 返回首页

完成标准：

- 同一天只能有一条校验主记录

#### D3. SOS 逻辑

- 记录来源为 `sos`
- 记录快速标签或描述
- 回首页

完成标准：

- 能在洞察页中看到 SOS 记录

### E. 体验与容错

#### E1. 自动保存

- 向导输入实时保存草稿
- 退出应用后可继续

完成标准：

- 中断不丢内容

#### E2. 软拦截

- 输入过短时不强禁用
- 用温柔文案提示

完成标准：

- 不出现硬性惩罚式阻断

#### E3. 离线可用

- 无网络不影响读写
- 错误文案保持平静

完成标准：

- 断网下可继续核心流程

## 3. 建议实现顺序

1. 数据库与 Repository
2. 应用状态中心
3. 路由守卫
4. 首次重构写库
5. 首页真实数据
6. 每日校验写库
7. SOS 写库
8. 洞察页读库
9. 自动保存与细节体验
