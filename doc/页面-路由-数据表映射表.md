# ResetSelf 页面 / 路由 / 数据表映射表

## 1. 说明

本表用于统一以下三类信息：

- 页面职责
- 路由入口
- 关联的数据表与核心字段

用于前端开发、数据落地和验收对照。

## 2. 页面映射总表

| 页面 | 当前路由 | 页面职责 | 主要数据表 | 核心字段 / 操作 |
|---|---|---|---|---|
| Bootstrap | `/bootstrap` | 启动初始化、本地数据检查、流程分流 | `user_profile` | 读取 `status`，决定跳转 |
| Onboarding_Vacuum | `/welcome` | 引导用户进入认知真空与首次重构 | 无强依赖 | 只负责说明与跳转 |
| Wizard_Reset | `/restructure/setup` | 首次 24h 重构 5 步输入与提交 | `restructure_record`、`limiting_belief`、`user_profile` | 写入反愿景、恐惧、信念、新身份、最小行动 |
| Home_Dashboard | `/home` | 展示身份宣言、最小行动、今日校验入口、SOS 入口 | `user_profile` | 读取 `identity_text`、`today_min_action`、`status` |
| Daily_Check | `/checkin` | 每日 1 分钟三态校验 | `daily_checkin`、`inertia_sample` | 写入 `check_date`、`match_status`、`system_comment` |
| SOS_Friction | `/sos` | 内耗急救、快速标签、样本收录 | `inertia_sample` | 写入 `source_type=sos`、`content`、`status_tag` |
| Insight_Deviation_Library | `/insights` | 展示最近偏差样本与 SOS 记录 | `inertia_sample`、`daily_checkin` | 按时间倒序查询最近记录 |
| Settings | `/settings` | 当前状态、调试入口、权限与作息配置 | `user_profile` | 当前先展示流程状态，后续扩展设置能力 |

## 3. 首次重构向导与数据映射

| 向导步骤 | 目标页面表现 | 数据落点 | 字段 |
|---|---|---|---|
| 反愿景 | 上午阶段问题 1 | `restructure_record` | `anti_vision` |
| 底层恐惧 | 上午阶段问题 2 | `restructure_record` | `fear_content` |
| 限制性信念 | 夜晚阶段问题 1 | `restructure_record`、`limiting_belief` | `belief_draft`、`content` |
| 新身份叙事 | 夜晚阶段问题 2 | `restructure_record`、`user_profile` | `identity_draft`、`identity_text` |
| 极简行动 | 夜晚阶段问题 3 | `restructure_record`、`user_profile` | `min_action_draft`、`today_min_action` |

提交完成后附加动作：

- `user_profile.status` 置为 `finished`
- 当前 `restructure_record.is_latest` 置为 `1`
- 旧版本 `is_latest` 置为 `0`

## 4. 每日校验与样本映射

| 用户动作 | 页面 | 主表 | 附加表 | 写入规则 |
|---|---|---|---|---|
| 完全匹配 | Daily_Check | `daily_checkin` | 可选写入 `inertia_sample` | 记录当天状态为 `match` |
| 部分偏离 | Daily_Check | `daily_checkin` | `inertia_sample` | 记录为偏差样本 |
| 完全偏离 | Daily_Check | `daily_checkin` | `inertia_sample` | 记录为完全偏离样本 |
| SOS 标签选择 | SOS_Friction | 无 | `inertia_sample` | `source_type=sos` |

建议状态映射：

| UI 状态 | 数据库存储值 |
|---|---|
| 完全匹配 | `match` |
| 部分偏离 | `partial` |
| 完全偏离 | `error` 或 `full_deviation` |

注：当前代码里需统一最终字段枚举，避免前端文案和数据库状态值不一致。

## 7. 路由守卫规则

| 条件 | 可访问页面 | 禁止访问页面 |
|---|---|---|
| `user_profile.status = uninit` | `/bootstrap`、`/welcome`、`/restructure/setup` | `/home`、`/checkin`、`/insights`、`/sos` |
| `user_profile.status = finished` | 全部核心页面 | 无 |
